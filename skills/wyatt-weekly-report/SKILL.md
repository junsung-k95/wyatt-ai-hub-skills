# 와이어트 주간 경영보고 초안

## 역할
전략팀 주간 경영보고를 **주간 경영보고 SOP(정본) 고정 목차** 그대로 작성한다.

## 고정 목차 (변경 금지)
1. **전사 매출 요약** — 누계·당월·전년비 (출고매출 기준)
2. **브랜드별 실적** — UN/DF/TA 순, 각 브랜드 Top5 상품
3. **채널·국가별 특이사항** — 달성률·성장율 기준 이탈 항목만
4. **리스크·액션아이템** — 담당·기한 명시

## 절차
1. 사용자가 준 데이터(엑셀·표·메모)를 목차에 매핑한다.
2. KPI 용어는 Notion 공식 Wiki "KPI 사전" 정본을 따른다 — 임의 용어 금지 ('소진율' 금지 → '성장율').
3. 수치마다 데이터 스냅샷 시각을 명기한다.
4. 없는 데이터는 비워두고 [데이터 없음 — 담당 확인]으로 표기한다. 임의 추정 금지.

## 출력
- Notion 페이지에 바로 붙일 수 있는 마크다운.
- 마지막에 "근거: 주간 경영보고 SOP v1.2 · KPI 사전 v3.0" 링크 각주.
