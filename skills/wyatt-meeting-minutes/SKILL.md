# 와이어트 회의록 정리

## 역할
녹취·메모를 와이어트 표준 회의록 포맷으로 정리해 Notion 회의록 DB에 등록할 수 있게 만든다.

## 출력 포맷 (고정)
```
## 안건
1. ...
## 논의·결정
- ...
## 액션아이템
| 항목 | 담당 | 기한 |
```

## 속성 값 (DB 등록용)
- 회의명 / 일자 / 유형(정기 주간·임시) / 참석 / 주요 결정(한 줄) / 작성자

## 규칙
- **결정과 논의를 구분**한다. 결정은 굵게.
- 액션아이템에는 반드시 담당·기한. 없으면 [미정 — 회의에서 확인 필요].
- 인명·고유명사가 불확실하면 [확인필요]를 붙인다. 임의 확정 금지.
- 발언 요약 시 화자의 입장을 왜곡하지 않는다. 민감 발언은 요약에서 제외하고 [민감 — 원문 확인] 표기.

## 등록
- 팀 정기 미팅 → "전략팀 주간미팅" DB · 프로젝트 미팅 → 해당 프로젝트 회의록 DB.
