## 1. 이 문서가 답해야 할 질문

> **AI서비스 하나가 기획에서 폐기까지 가는 동안, 각 단계에서 누가 무엇을 하고 무엇으로 통과 여부를 가르는가?**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. **4.3.1 라이프사이클** — 단계 정의(기획→타당성검토→데이터확보→개발/도입→평가검증→승인→배포→운영모니터링→재평가→폐기). **도입 방식(자체개발 / 외부솔루션 이용)에 따라 갈라지는 지점을 명시**. 단계별 매뉴얼 3종(개발·이용 / 평가·검증 / 소비자보호)의 목차 제시. 민원·분쟁·소송·장애 대처 절차(에스컬레이션 경로·시한). **담당자 교체에도 작동하도록 하는 장치**(매뉴얼에 서식·화면·판단기준 내장, 인수인계 체크리스트)
2. **4.3.2 체크리스트** — 「금융분야 인공지능 가이드라인」의 **실제 점검항목을 찾아** 라이프사이클 단계에 배치. 체크리스트 문항 예시를 단계별 3~5개씩 실제 문장으로 제시. 게이트 통과 판정 규칙(전항목 충족 / 조건부 통과 / 반려)과 판정 권한자
3. **4.3.3 현업주도** — 현업·IT·리스크·준법·정보보호의 단계별 RACI. 현업이 무엇을 스스로 하고 어디서 지원받는지. 현업 신청 → 사전 상담 → 접수 → 게이트 진입의 실제 흐름
4. **4.3.4 성과측정** — 서비스 유형별(생성형 상담지원 / 심사·분류 모델 / 내부 업무자동화) 성과지표 세트와 **산식**. 측정 주기·데이터 소스·보고 라인. 성과 미달 시 환류(개선/중단) 판정 기준
5. **4.3.5 당국 소통** — 혁신금융서비스 지정~개시 절차 전체를 단계표로(신청·지정·부가조건·개시신고·경과보고). 기간연장/변경신청 요건과 서류. 금보원 보안성 검토 대응(실사자료 목록, 현장점검 예상 질의와 준비물). 금감원 클라우드컴퓨팅 이용보고 제출 서류. **실제 케이스 기반 직원 교육 프로그램**(SC2-18) 커리큘럼
6. **4.3.6 설명가능성·증적** — 규제기관 검사·보고 요구에 대응하는 자료 생성 체계. 남길 증적 항목(학습데이터 출처·전처리 이력, 알고리즘 선택 근거, 주요 변수 영향도, 검증 결과, 승인 이력). 보관 위치·기간·접근권한. 요구 접수 시 산출까지의 대응 시한
7. **금융분야 인공지능 가이드라인의 점검항목을 반드시 원문에서 확인해 인용**할 것

## 6. 시각화 방향

① 라이프사이클 가로 흐름도(단계 10개, 개발/이용 분기 표시, 게이트를 마름모로) ② 게이트별 체크리스트 카드 ③ RACI 매트릭스 표 ④ 성과지표는 3분할 가로(서비스 유형 3종) ⑤ 당국 소통은 4분할 세로 흐름(신청→지정→개시→경과보고) ⑥ 증적 관리는 라이프사이클 축 위에 증적 적재 지점 오버레이.

위는 방향 제시일 뿐이다. `## 4. 시각적 표현 방안`에서 **슬라이드 분할 패턴 · 도해 지시 · 표/차트 사양** 3가지를 모두 구체화할 것.
