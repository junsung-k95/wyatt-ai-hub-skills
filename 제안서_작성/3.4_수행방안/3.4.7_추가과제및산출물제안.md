# Ⅲ.4.7 추가 과제 및 산출물 제안 (규제 요구 확대 대응)

> **메타** | 요구사항: `GM-17, PD-I-2c` | Phase: Phase1·Phase2·전기간 | 예상 분량: 3장

---

## 1. 거버닝 메시지

> **RFP가 「예시적 범위」라고 밝힌 이상 능동적 확대는 선택이 아니라 요구이므로, 제안 단계에서 이미 AI기본법 시행령·가이드라인 점검항목·보안 안내서를 조항 단위로 대조하여 RFP 산출물 19종에 대응물이 없는 규제 의무 9건을 찾아냈고, 그중 8건을 기본 범위 내에서 무상 수행하고 1건만 별도 공수로 구분해 제시한다.**

- **서브메시지 1** — 추가 과제는 아이디어가 아니라 **미대응 의무**다. 각 항목은 `규제 근거 조항 → 없을 경우의 리스크 → 제안 산출물 → 추가 공수 여부` 4요소를 갖추며, **근거 조항이 특정되지 않은 항목은 제시하지 않았다.**
- **서브메시지 2** — 9건 중 **ADD-2·ADD-7은 Phase1 대상**이다. 10월 개시 전에 이행되지 않으면 그 자체가 법령 위반 또는 실사 지적 사유가 되므로, 추가 제안이면서도 **우선 처리 대상**이다.
- **서브메시지 3** — **8건은 기본 범위 내 무상 흡수**한다. 기존 산출물의 장(章)·별표·부속 서식 추가로 해결되기 때문이다. 별도 공수는 **ADD-5 한 건**뿐이며, 그 사유와 예상 규모를 명시하여 발주처의 비용 판단 자료로 제공한다.

## 2. 본문

### 2.1 도출 방법 — 무엇과 무엇을 대조했는가

RFP Ⅱ-3은 *"명시된 과제 및 산출물은 예시적 범위로서, 인공지능 기본법·금융분야 인공지능 가이드라인·AI RMF 등 관련 법령 및 규제 기준에서 요구하는 사항이 추가로 확인될 경우, 제안사는 이를 능동적으로 파악하여 필요한 과제 및 산출물을 추가 제시하여야 한다"* 고 규정한다.

이에 따라 **제안 작성 단계에서 다음 대조를 수행**했다.

| 대조 대상 | 대조 방법 | 결과 |
|---|---|---|
| AI기본법 제31~35조 및 시행령 제23~28조 | 각 조항의 의무를 RFP 산출물 19종과 1:1 대조 | 대응물 없는 의무 **3건** 발견 |
| 금융분야 인공지능 가이드라인 점검항목 99개 | 각 항목의 충족을 증명할 산출물 존재 여부 확인 | 대응 산출물 없는 항목군 **4건** 발견 |
| 금융분야 AI 위험관리 프레임워크 | 3.2~3.4의 요구사항과 산출물 대조 | 대응물 없는 항목 **1건** 발견 |
| 금융분야 인공지능 보안 안내서 제2~7장 | 각 장의 통제와 산출물 대조 | 대응물 없는 항목 **1건** 발견 |
| 개인정보보호법·신용정보법 | AI 학습·추론 관련 의무 대조 | 대응물 없는 의무 **1건** 발견 |
| | **계** | **9건** (일부 중복 제거 후) |

**Ⅲ.2.4의 트리거 유형과의 대응** — 아래 9건은 T1(법령 의무 중 대응물 없음) 3건, T2(점검항목 중 충족 증명 불가) 5건, T4(신설 규범 대응) 1건에 해당한다.

### 2.2 추가 과제 및 산출물 9건

#### ADD-1. 고영향 AI 영향평가서

| 요소 | 내용 |
|---|---|
| **규제 근거 조항** | **AI기본법 제35조제1항** — *"인공지능사업자가 고영향 인공지능을 이용한 제품 또는 서비스를 제공하는 경우 사전에 사람의 기본권에 미치는 영향을 평가하기 위하여 노력하여야 한다. 이 경우 영향평가에는 인공지능취약계층의 특성이 반영될 수 있도록 하여야 한다"*<br>**동 시행령 제28조제1항** — 영향평가 포함 사항 **7개** : ① 영향받을 개인·집단 식별(취약계층 특성 반영) ② 영향받을 기본권 유형 식별 ③ 사회적·경제적 영향의 내용 및 범위 ④ 사용 행태 ⑤ 정량·정성 평가지표 및 결과산출 방식 ⑥ 위험의 예방·완화·손실 복구 ⑦ 개선 필요 시 이행계획 |
| **없을 경우의 리스크** | 수협의 여신 심사·신용평가 AI는 **AI기본법 제2조제4호 사목**(대출 심사 등 개인의 권리·의무 관계에 중대한 영향을 미치는 판단 또는 평가)에 해당할 가능성이 높다. 고영향 판정 시 영향평가는 법이 요구하는 노력 의무이며, **RFP 산출물 19종에는 이를 담는 문서가 없다.** 위험평가서(DL1-3)는 **회사 관점의 위험**을 평가하는 문서이고, 영향평가는 **개인의 기본권 관점**을 평가하는 문서로 목적과 항목이 다르다. 미수행 시 감독당국·과기정통부 확인 요청 시 소명 자료가 없다 |
| **제안 산출물** | **고영향 AI 영향평가서** — 시행령 제28조제1항 7개 항목 전건을 목차로 구성. 고영향 판정 서비스별 작성. 평가지표와 결과산출 방식을 명시하고, 취약계층(고령자·장애인·금융 이력 부족자) 특성 반영 섹션 포함 |
| **추가 공수** | **기본 범위 흡수** — 위험평가(DL1-3) 수행 시 수집하는 자료를 재사용하며, 평가 관점만 추가하면 되므로 별도 공수를 요청하지 않는다 |
| **Phase** | Phase2 (10월 3개 과제 중 고영향 판정 건은 Phase1에 선행 수행) |

| 요소 | 내용 |
|---|---|

| **제안 산출물** | **AI 관련 공시·게시 자료 패키지** — ① 4개 항목의 게시 문안 ② 영업비밀 해당 여부 검토 결과(준법감시 확인) ③ 게시 위치 및 방법 ④ 관리·감독자 지정 및 표기 방식(개인정보 최소화 원칙 적용) ⑤ 갱신 주기 및 갱신 책임자 ⑥ 게시 이력 관리표 |
| **추가 공수** | **기본 범위 흡수** — DL1-1(AI 업무규정) 및 AI윤리원칙 공시 작업과 함께 수행 |
| **Phase** | **Phase1** — 10월 개시 시점에 고영향 판정 서비스가 있으면 개시와 동시에 게시 의무가 발생한다 |

| **추가 공수** | **기본 범위 흡수** — DL1-1의 AI 보안 준칙 및 DL2-4 소비자보호 매뉴얼과 연계하여 독립 절차서로 구성 |
| **Phase** | Phase2 (10월 개시 전 **긴급정지 기준과 보고 절차만 선(先)확정**하여 Phase1에 적용) |

### 2.4 이 절이 갖는 의미

RFP Ⅱ-3의 능동적 확대 요구는 **제안사가 규제를 먼저 읽었는지를 확인하는 조항**이다. 본 절의 9건은 다음 세 가지를 보인다.

1. **조항 단위로 대조했다** — 9건 모두 근거 조항이 특정되어 있고, 항목 번호까지 인용된다. "AI 규제가 강화되고 있으므로 대응이 필요하다"는 일반론이 아니다.
2. **RFP 산출물과의 차이를 설명했다** — 각 항목마다 *"왜 기존 19종으로는 커버되지 않는가"* 를 명시했다. 예: 위험평가서는 회사 관점, 영향평가는 기본권 관점(ADD-1) / 데이터 거버넌스 정의서는 체계, 적법성 검토서는 개별 판정(ADD-5) / 보안대책서는 혁신금융서비스 대상, 내부망 연계는 별도(ADD-8).
3. **비용 판단 자료를 제공했다** — 8건을 무상 흡수하고 1건만 별도 공수로 구분함으로써, 발주처가 **추가 제안을 비용 증가 요구로 받아들이지 않도록** 했다.

**사업 착수 후의 확대** — 본 절은 **제안 시점에 발견한 것**이다. 사업 중 발견되는 항목은 Ⅲ.2.4의 능동 확대 트리거(T1~T4)와 공수 판정 기준(장·서식 추가로 해결되면 기본 범위, 독립 문서 + 5인일 초과 시 별도 공수)에 따라 처리하고, 새 ID(`ADD-nn`)를 부여하여 요구사항 추적표에 등재한다.

## 3. 제안서용 요약 · 논리 구조

**논리 골격 : [요구의 성격] → [대조 방법] → [발견 9건] → [공수 판정] → [의미]**

- **[요구의 성격]** RFP Ⅱ-3 「예시적 범위」 + 능동적 파악·추가 제시 요구 → **선택이 아니라 요구**
- **[대조 방법]** 5개 규범군을 **조항 단위로 RFP 산출물 19종과 1:1 대조** → 미대응 **9건**
  - AI기본법·시행령 3건 / 가이드라인 점검항목 4건 / AI RMF 1건 / 보안 안내서 1건 / 개인정보·신용정보법 1건 (중복 제거)
- **[발견 9건]** 각각 **근거 조항 → 리스크 → 제안 산출물 → 공수** 4요소
  - **ADD-1 고영향 AI 영향평가서** ← 법 §35·령 §28① **7개 항목** / *위험평가서는 회사 관점, 영향평가는 기본권 관점*
  - **ADD-2 공시·게시 패키지** ← **령 §27① 4개 게시 항목** / *윤리원칙 공시와 별개의 법정 의무*, **Phase1**
  - ADD-3 제3자 위험관리 기준·등록부 ← 가이드라인 5.3 및 점검항목 ③④⑤⑥, ㉒㉗
  - ADD-4 AI 사고·침해 대응 절차서 ← 점검항목 ⑦⑧⑨·㉟, RMF 3.4.6 / *AI 고유 사고는 기존 IT 장애 절차로 미포섭*
  - **ADD-5 학습데이터 적법성 검토서** ← 개인정보보호법·신용정보법 §22의3·§36의2, RMF 「데이터 관련법」·「품질」 / *정의서는 체계, 검토서는 개별 판정* → **유일한 별도 공수**
  - ADD-6 규제 추적 등록부 이관본 ← 점검항목 ⑩⑪ / *이관하지 않으면 종료와 함께 체계 소멸*
  - **ADD-7 안전성 확보 의무 검토 확인서** ← 법 §32·령 §24①(**10²⁶ FLOP**) / *"미해당"도 문서로 남겨야 증명됨*, **Phase1**
  - ADD-8 생성형 AI 내부망 연계 보안대책 확인서 ← 점검항목 **㊱**, 보안 안내서 제7장 / *DL2-1은 혁신금융서비스 대상*
  - ADD-9 오픈소스 AI 활용 관리대장 ← 점검항목 **㊲**, 제5장 공급망 보안
- **[공수 판정]** **9건 중 8건 기본 범위 무상 흡수 / 1건(ADD-5)만 별도 공수 검토**
  - ADD-5 사유 : 데이터셋 개별 판정(수량 비례) + 법률 검토 역량 별도 투입 + 원 동의서·약관 확인 범위
  - 예상 규모 20건 기준 **15~20인일**, 단 **10월 3개 과제 관련분은 기본 범위 포함**
- **[의미]** ① **조항 단위 대조** — 일반론 아님 ② **RFP 산출물과의 차이 설명** — 왜 19종으로 커버 안 되는지 ③ **비용 판단 자료 제공** — 추가 제안이 비용 증가 요구로 읽히지 않게
  - 착수 후 발견분은 Ⅲ.2.4 트리거·공수 기준으로 처리하고 `ADD-nn` ID 부여 후 추적표 등재

## 4. 시각적 표현 방안

### (a) 슬라이드 분할 구조 — 3장

- **1장 : `좌우 2분할 비교`** — 왼쪽 「RFP 기본 범위(19종)」 ↔ 오른쪽 「추가 제안 범위(9건)」, 하단에 대조 방법
- **2장 : `전면 카드 세로 반복`** — 추가 과제 카드 9개(3열 × 3행), 각 카드에 4요소
- **3장 : `상하 2분할`** — 위 = 총괄표 및 공수 판정, 아래 = 착수 후 확대 절차 연결

### (b) 도해 지시

**1장 — 기본 범위 ↔ 추가 제안 대비도**
- 좌측 : RFP 산출물 19종을 4개 계열 블록(DL1 9 / DL2 6 / DL3 2 / DL4 2)으로 배치. 차분한 기본색
- 우측 : 추가 9건을 카드로 배치. 강조색
- **중앙에 5개 규범 아이콘 열**(AI기본법·시행령 / 가이드라인 점검항목 99 / AI RMF / 보안 안내서 / 개인정보·신용정보법)을 세로로 세우고, 각 규범에서 **좌측(대응됨)과 우측(미대응)으로 화살표를 뻗는다**
- 우측으로 향하는 화살표에 **근거 조항 배지**(`령 §27①` `점검항목 ㊱` `법 §32` 등)를 붙인다. **조항 번호가 화살표마다 붙어 있는 모습**이 이 슬라이드의 증명 장치
- 좌측 블록 상단에 `19종`, 우측 상단에 `+9건`, 그 아래에 **`8건 무상 / 1건 별도 공수`** 를 배지로
- 하단 가로 띠 : 대조 방법 5행 요약(대조 대상 / 방법 / 발견 건수)

**2장 — 추가 과제 카드 9개**
- 3열 × 3행 그리드. 각 카드 4개 슬롯을 **동일한 위치**에 배치하여 세로로 훑을 때 같은 요소가 정렬되어 보이게 한다
  1. 상단 : `ADD 번호 + 산출물명` + **Phase 배지**(P1은 적색)
  2. 중상단 : **`규제 근거`** — 조항 번호를 굵게, 핵심 문구를 인용부호로
  3. 중하단 : **`없을 경우 리스크`** — 경고 아이콘 + 1~2문장
  4. 하단 : **`공수`** — `기본 범위 흡수`(8건, 기본색) / `별도 공수 검토`(1건, 강조색)
- **ADD-5 카드만 하단 슬롯이 강조색**이 되어 9장 중 1장만 다른 색인 모습이 드러난다
- **ADD-2·ADD-7 카드는 상단 Phase 배지가 적색(P1)** — 우선 처리 대상임을 표시
- 각 카드 우하단에 **편입 대상 배지**(DL1-1 장 편입 / DL1-4 장 편입 / 신규 문서 등)

**3장 상단 — 총괄표 및 공수 판정**
- 9행 표(번호 / 산출물 / 근거 유형 / Phase / 공수 / 편입 대상)
- 「공수」 열의 `기본 범위 흡수` 8개 셀을 **동일한 옅은 색으로 통일**하고, `별도 공수 검토` 1개 셀만 강조 테두리
- 표 우측에 요약 블록 : **`9건 발견 / 8건 무상 / 1건 별도`** 를 큰 숫자로
- ADD-5 행 아래에 별도 주석 박스 : 별도 공수 사유 3개와 예상 규모(20건 기준 15~20인일), **「10월 3개 과제분은 기본 범위 포함」** 을 굵게

**3장 하단 — 착수 후 확대 절차 연결**
- 좌→우 흐름 : `Ⅲ.2.4 규제 추적` → `트리거 T1~T4 발동` → `근거 조항 특정` → `리스크 서술` → `산출물 정의` → `공수 판정(장·서식 추가 → 기본 / 독립 문서 + 5인일 초과 → 별도)` → `ADD-nn ID 부여` → `추적표 등재`
- 흐름의 시작 지점에 **「본 절 = 제안 시점 발견분」** 라벨을 붙이고, 같은 흐름이 사업 중에도 반복됨을 순환 화살표로 표시
- *"본 절은 착수 전에 이미 한 바퀴 돌린 결과"* 라는 주석

## 5. 인접 절과의 경계 / 인용 근거

### 경계 자기점검

- **Ⅲ.2.4(규제 변화 추적)와의 경계 — 이 절에서 가장 중요한 경계** : Ⅲ.2.4는 **추적·반영 메커니즘**(추적 대상 16개, 모니터링 주기, 영향도 3단계 판정, 보고·반영 시한, 능동 확대 트리거 T1~T4, 공수 판정 기준)을 담당한다. 본 절은 **그 메커니즘을 제안 시점에 이미 한 번 돌려 나온 결과**다. 트리거 조건이나 판정 절차를 재기술하지 않았고, 발견된 9건의 내용만 제시했다.
- **Ⅲ.3.3(산출물 체계)과의 경계** : 추가 산출물 6종의 **목록 표기**는 Ⅲ.3.3에 있고, 본 절은 **근거 조항·리스크·공수 판정**을 담당한다. 본 절에서 9건으로 확대되었으므로, Ⅲ.3.3의 추가 제안 목록(6종)은 본 절과 대조하여 최종본에서 9종으로 정합시킨다.
- **Ⅲ.4.6(산출물 목록·소유권)과의 경계** : 추가 산출물의 **구성 항목·분량·형식·권리 구분**은 Ⅲ.4.6이 담당한다. 본 절은 **왜 필요한가**를 담당한다.
- **Ⅲ.4.2~4.5와의 경계** : 각 추가 산출물이 편입되는 기존 산출물(DL1-1·DL1-4·DL1-7·DL2-1)의 내용은 해당 절이 담당한다. 본 절은 **편입 대상만 지정**했다.
- **Ⅲ.4.1과의 경계** : 진단 결과 과제1~4 어디에도 배정되지 않는 개선과제가 본 절의 추가 제안으로 이어진다는 **전환 규칙**은 Ⅲ.4.1이 정의했다. 본 절은 그 규칙의 **제안 시점 적용 결과**다.
- **Ⅰ.2(제안범위 및 추진전략)와의 관계** : PD-I-2c(추가제안 사항의 구체적 제시)는 Ⅰ.2에서도 요약 언급되나, **상세 근거와 공수 판정은 본 절**이 담당한다.

### [가정] 목록

- **[가정]** 9건은 **제안 작성 시점(2026년 7월)에 확인된 규범을 기준으로 도출**한 것이다. 착수 시점에 규범이 개정되었으면 Ⅲ.2.4의 추적 절차에 따라 재대조하고 목록을 갱신한다.
- **[가정]** ADD-1(영향평가서)의 필요 여부는 **수협의 AI서비스 중 고영향 AI 해당 건이 존재하는지**에 달려 있다. 여신 심사·신용평가 관련 AI가 법 제2조제4호 사목에 해당할 가능성이 높다고 판단하였으나, 최종 판정은 착수 후 진단(Ⅲ.4.1 영역 3)에서 수행한다. 해당 건이 없으면 ADD-1은 **판정 근거 문서만 작성**하고 평가서는 작성하지 않는다.
- **[가정]** ADD-2(게시 패키지)의 이행 시점은 고영향 AI 서비스의 제공 개시 시점에 연동된다. 10월 개시 서비스 중 고영향 판정 건이 없으면 Phase2로 이연한다.
- **[가정]** ADD-5의 예상 공수(데이터셋 20건 기준 15~20인일)는 제안사의 유사 사업 경험에 근거한 추정치다. **대상 데이터셋 수와 원 동의서·약관 자료의 확보 상태**에 따라 변동하므로, 착수 후 진단(Ⅲ.4.1 영역 4)에서 대상 수를 확정한 뒤 재산정하여 발주처에 제시한다. 재산정 결과가 추정치를 초과해도 **10월 3개 과제 관련분은 기본 범위에서 무상 수행**한다.
- **[가정]** ADD-7(안전성 확보 의무 검토)에서 수협이 **직접 대규모 사전학습을 수행하지 않는 것**을 전제로 「대부분 미해당」으로 예상하였다. 자체 사전학습 계획이 확인되면 해당 여부를 실측 기준으로 판정하고, 해당 시 법 제32조제2항의 이행 결과 제출 절차를 별도 과제로 제시한다.
- **[가정]** ADD-8(생성형 AI 내부망 연계)의 필요 여부는 **상용 생성형 AI를 내부망에서 이용하는지**에 달려 있다. 이용하지 않으면 해당사항 없음으로 처리하고, 그 판정 사실을 DL2-1에 기재한다.
- **[가정]** ADD-9(오픈소스 관리대장)가 참조하는 「금융분야 오픈소스 소프트웨어 활용·관리 안내서」는 가이드라인 점검항목 ㊲에서 인용된 문서다. 해당 안내서의 최신본을 착수 시 확보하여 대장 항목을 정합시킨다.
- **[가정]** 「기본 범위 흡수」로 판정한 8건은 **기존 산출물의 장(章)·별표·부속 서식 추가 또는 기존 작업의 산출 정리로 해결된다**는 제안사 판단에 근거한다. 착수 후 범위가 예상보다 확대되면 Ⅲ.2.4의 공수 판정 기준(독립 문서 + 5인일 초과)을 적용하여 재판정하고, 재판정 결과를 발주처에 사전 제시한다.
