# Ⅲ.2.5 사업 위험요소 및 대응 방향

> **메타** | 요구사항: `PD-III-2a, PD-III-3c` | Phase: 전기간 | 예상 분량: 2장

---

## 1. 거버닝 메시지

> **이 사업이 실패한다면 그것은 산출물을 못 써서가 아니라 「합의가 나지 않아서·승인이 늦어서·외부 일정이 바뀌어서」이므로, 위험 레지스터를 제안사 통제 가능성 기준으로 재배열하고 통제 불가 위험 4건에는 발생 전 조치와 발생 후 대체 경로를 각각 확정형으로 지정한다.**

- **서브메시지 1** — 위험 10건을 식별했고, 그중 **고위험 3건은 모두 제안사가 단독으로 해소하지 못하는 위험**이다(내부 승인 지연 / 중앙회 합의 결렬 / 금보원 지적 발생). 위험 관리의 초점을 여기에 둔다.
- **서브메시지 2** — 각 위험에 **징후(트리거)를 관측 가능한 사건으로 정의**한다. "지연이 우려된다"가 아니라 "D+30 상정 마감일에 안건이 접수되지 않았다"처럼 날짜와 사실로 판정한다.
- **서브메시지 3** — 대응은 「모니터링한다」로 끝내지 않는다. 각 위험마다 **발생 전 예방 조치**와 **발생 후 대체 경로**를 별개로 지정하고, 대체 경로에는 발동 조건과 결정 주체를 명시한다.

### 2.2 위험 대응표 — 5요소

각 위험을 **[발생 시점 / 징후(트리거) / 영향 / 예방책 / 발생 시 대응]** 5요소로 정의한다.

#### R-01 Phase1 기간 부족 〔고〕

| 요소 | 내용 |
|---|---|
| **발생 시점** | D+30 전후, Phase1 중반 |
| **징후(트리거)** | ① D+31 시점 잔여 버퍼가 **10일 미만**으로 감소 ② 초안 인수 대상 4건 중 **2건 이상이 예정일을 3영업일 초과** |
| **영향** | Phase1 산출물 9건 중 후행 3건(DL1-5, DL4-2, DL2-2)의 확정이 D+60을 넘김 → 10월 개시 승인 근거 미비 |
| **예방책** | ① 착수 D+10까지 「Phase1 확정 일정표」를 발주처와 합의하여 기준선을 고정한다 ② 초안 인수 2단계 방식으로 발주처 내부 절차를 병행 착수시킨다 ③ 잔여 버퍼를 **주간 보고 고정 항목**으로 계측한다 |
| **발생 시 대응** | ① 산출물 확정 순서를 **10월 개시에 직접 필요한 5건(DL1-1, DL1-3, DL1-5, DL2-1, DL2-2)** 으로 좁히고 나머지 4건은 Phase2 초반으로 재배치하는 안을 발주처에 제시한다 ② 규범 계열 인력을 보안 계열로 **1주 단위 전환 투입**한다 ③ 재배치 결정은 **D+35 이전에** 확정한다(그 이후는 만회 효과가 없다) |

#### R-02 발주처 내부 승인 지연 〔고 · 통제 불가〕

| 요소 | 내용 |
|---|---|
| **발생 시점** | D+30(이사회 상정 마감) |
| **징후(트리거)** | ① 착수 D+3 확인 결과 이사회 주기가 **격월 이상**이거나 잔여 개최 회차가 Phase1 내 1회 이하 ② 임원 개별 협의에서 책무 배분안에 **이견이 제기**되어 D+24까지 준법·감사 검토가 착수되지 않음 |
| **영향** | DL1-2(책무구조도) 확정이 Phase1을 넘김 → AI 관련 내부통제 책임 소재가 미확정 상태로 10월 개시 |
| **예방책** | ① 착수 **D+1**에 이사회 일정과 상정 마감을 확인하여 역산 고정 ② 임원 개별 협의를 순차가 아닌 **동일 주간 병렬 면담**으로 설계 ③ 책무 배분안을 **1안이 아니라 2안(집중형 / 분산형)** 으로 제시하여 협의를 선택 문제로 전환 |
| **발생 시 대응** | ① **Phase1 종료 조건을 「의결 완료」에서 「상정 완료」로 재정의**하는 안을 발주처에 제시하고 합의서로 남긴다 ② 의결 전 기간에는 **현행 책무구조도 하의 잠정 책임 배분**을 AI실무협의회 의결로 정하여 거버넌스 승인서 발급 근거를 확보한다 ③ 잠정 배분과 최종 의결본의 차이는 의결 직후 **차분 반영**한다. 결정 주체 = 발주처 AX혁신실 및 준법감시부 |

#### R-03 중앙회 비용배분 합의 결렬·지연 〔고 · 통제 불가〕

| 요소 | 내용 |
|---|---|
| **발생 시점** | D+38(권고안 확정) ~ D+55(서명) |
| **징후(트리거)** | ① D+24 시산 결과 회람 후 **10영업일 내 중앙회 회신이 없음** ② 회신 의견이 배분 방식의 **전제 자체를 부정**(예: 공동이용 범위 자체에 이견) ③ 중앙회 내부 품의 절차가 D+45까지 착수되지 않음 |
| **영향** | DL4-1 미서명 → 업무위수탁 부속협약 체결 불가 → **상호금융 AI서비스 제공의 계약 근거 부재**(GM-07 미달성) |
| **예방책** | ① 협의체를 **D+7에 구성**하여 착수 첫 주에 상대를 테이블에 앉힌다 ② 배분 방식을 **대안 3안 + 각 안의 기관별 시산 금액**으로 동시 제시하여 논의를 "찬반"이 아닌 "선택"으로 전환한다 ③ 쟁점을 **①공동이용 범위 ②배분 기준 ③정산 주기** 3개로 미리 분해하여, 하나가 막혀도 나머지가 진행되게 한다 |
| **발생 시 대응** | ① **단계적 합의**로 전환한다 — 전체 합의를 기다리지 않고 「공동이용 범위」와 「정산 주기」를 먼저 확정한 **부분 합의서**를 체결하고, 배분 비율은 **잠정 비율 + 사후 정산 조항**으로 처리한다 ② 잠정 비율은 **최초 6개월 균등분담 후 실사용량 기준 소급 정산**을 기본안으로 제시한다 ③ D+50까지 부분 합의도 성립하지 않으면 발주처에 **에스컬레이션**하고, 미합의 사실과 사유·대안을 문서로 제출하여 Phase1 산출물의 상태를 명확히 한다 |

#### R-04 금융보안원 실사 지적사항 발생 〔중 · 통제 불가〕

| 요소 | 내용 |
|---|---|
| **발생 시점** | 현장점검일(≒D+45) 및 그 이후 |
| **징후(트리거)** | ① 자체 사전점검(D+24)에서 가이드라인 보안성 원칙 점검항목 38개 중 **미충족 3개 이상** ② 실사자료 제출 후 금융보안원의 **추가 자료 요구 2회 이상** |
| **영향** | 보완·재검토로 검토 완료일이 밀려 개시일 대비 여유(S-21일) 소진 |
| **예방책** | ① 실사자료를 **점검일 기준이 아니라 「사양 확보일 + 35일」 기준으로 완성**하여 점검일 변동에 무관하게 준비 상태를 유지한다 ② 자체 사전점검을 **AI 기획·개발·운영자가 아닌 별도 인력**이 수행한다(보안 안내서 제1장 「적용 참고사항」이 명시한 요건) ③ 예상 질의 대응표를 작성하고 현장점검에 **배석**한다 |
| **발생 시 대응** | ① 지적 접수 즉시 **5영업일 내 보완자료 제출**을 원칙으로 하고, 보완 작업을 위해 규범 계열 인력을 즉시 전환 투입한다 ② 지적 유형이 **설계 결함**(보완으로 해소되지 않는 유형)이면 해당 과제를 **개시 대상에서 후순위로 분리**하는 안을 발주처에 즉시 제시한다 — 3개 과제 전체를 지연시키지 않기 위함이다 |

### 2.3 위험 관리 운영 방식

- **주간 보고 고정 항목** — 잔여 버퍼 일수 / A등급 규제 변경 누적 건수 / 자료 미제출 항목 수 / 보류 조문 수 / 실질 상충 비율. 이 5개 지표가 위 트리거의 관측 값이다.
- **에스컬레이션 기준** — 고위험 3건(R-01·R-02·R-03) 중 어느 하나라도 트리거가 관측되면 **주간 보고를 기다리지 않고 1영업일 내 발주처 사업담당자에게 보고**하고, 대응안을 3영업일 내 제시한다.
- **위험 레지스터 갱신** — 격주 1회 갱신하며, 신규 위험은 동일한 5요소 형식으로 등재한다.

## 3. 제안서용 요약 · 논리 구조

**논리 골격 : [실패 지점 규정] → [위험 배열] → [트리거 관측화] → [예방/대체 이원 대응] → [운영]**

- **[실패 지점 규정]** 이 사업은 **문서를 못 써서 실패하지 않는다** → *합의가 안 나서 · 승인이 늦어서 · 외부 일정이 바뀌어서* 실패한다
- **[위험 배열]** 10건을 **통제 가능성 기준으로 재배열** — 통제 불가 4건(R-02·R-03·R-04·R-05) / 부분 통제 5건 / 통제 가능 1건
  - **고위험 3건은 전부 제안사 단독 해소 불가** : R-01 기간 부족 · R-02 내부 승인 지연 · R-03 중앙회 합의 결렬
- **[트리거 관측화]** "우려된다" ✗ / **날짜·수치로 판정** ○
  - 예 : *잔여 버퍼 10일 미만* / *이사회 잔여 회차 1회 이하* / *시산 회람 후 10영업일 무회신* / *사전점검 미충족 3개 이상* / *실질 상충 20% 초과*
- **[이원 대응]** 위험마다 **예방책(발생 전)** 과 **대체 경로(발생 후)** 를 분리 지정, 대체 경로에 **발동 조건 + 결정 주체** 명시
  - R-02 → **Phase1 종료 조건을 「의결」에서 「상정 완료」로 재정의** + 잠정 책임 배분으로 승인서 근거 확보
  - R-03 → **단계적 합의** : 범위·주기 먼저 확정 + **잠정 비율(6개월 균등 후 실사용량 소급 정산)**
  - R-04 → 설계 결함형 지적 시 **해당 과제만 후순위 분리** (3개 전체를 지연시키지 않음)
  - R-01 → **D+35 이전에** 산출물 5건으로 범위 축소 결정(그 이후는 만회 효과 없음)
- **[운영]** 주간 보고 5개 지표 = 트리거 관측값 / 고위험 3건은 **1영업일 내 즉시 보고** / 레지스터 격주 갱신

## 4. 시각적 표현 방안

### (a) 슬라이드 분할 구조 — 2장

- **1장 : `중앙 다이어그램 + 주변 설명`** — 중앙에 위험 히트맵 2×2, 주변에 고위험 3건 확대 카드
- **2장 : `전면 표`** — 위험 대응표 10건 × 5요소. 하단에 주간 보고 지표 띠

### (b) 도해 지시

**1장 중앙 — 위험 히트맵**
- 가로축 = **발생 가능성**(좌 낮음 → 우 높음), 세로축 = **영향도**(하 낮음 → 상 높음)
- 위험 10건을 원형 노드로 배치, 노드 안에 ID(R-01 등)
- **노드의 테두리로 통제 가능성을 표현** : 실선 = 통제 가능 / 파선 = 부분 통제 / **점선 + 자물쇠 아이콘 = 통제 불가**. 우상단(고위험) 사분면에 점선 노드가 몰려 있는 모습이 이 도해의 핵심 메시지 — *"가장 위험한 것이 우리가 통제하지 못하는 것"*
- 우상단 사분면을 적색 음영, 「즉시 보고 대상」 라벨
- 각 노드에 트리거 아이콘(눈 모양)을 부착하고, 마우스오버 대신 **하단 범례로 트리거 문구를 연결**

**1장 주변 — 고위험 3건 확대 카드 (좌·우·하단)**
- 각 카드 5개 슬롯 : `위험명` / `트리거(수치)` / `영향` / `예방책` / `대체 경로`
- **「대체 경로」 슬롯만 다른 배경색**으로 처리하고 발동 조건 배지 부착 — 예방과 대응이 별개 장치임을 시각화
- R-02 카드 : 대체 경로 = *"Phase1 종료 조건 재정의 : 의결 → 상정 완료"* 를 굵게
- R-03 카드 : 대체 경로 = *"단계적 합의 + 잠정 비율 6개월 균등 → 실사용량 소급"* 을 굵게
- 카드 우측 상단에 통제 불가 주체 배지 : `이사회` / `중앙회` / `금융보안원`

**2장 — 위험 대응표 전면 배치**
- 10행 × 6열 표. 등급별로 행 배경색 구분(고 = 진함 / 중 = 중간 / 저 = 옅음)
- 「발생 시 대응」 열의 셀에는 **번호가 붙은 조치 문장**을 그대로 넣어 확정형임을 드러낸다
- 표 좌측에 세로 색 띠로 통제 가능성 3단 표시

**2장 하단 — 주간 보고 지표 띠**
- 가로 5분할 : `잔여 버퍼(일)` / `A등급 규제변경(건)` / `자료 미제출(항목)` / `보류 조문(건)` / `실질 상충(%)`
- 각 칸에 **경고 임계값**을 명시 : `<10` / `>3` / `>0` / `>0` / `>20%`
- 띠 우측에 *"임계값 도달 = 1영업일 내 보고"* 라벨

### (c) 표·차트 사양

**표1. 위험 대응표 (10건 × 5요소)**

| 컬럼 | 내용 |
|---|---|
| ID | R-01~R-10 |
| 위험 | 명칭 |
| 등급 | 고 / 중 / 저 |
| 통제 가능성 | 통제 가능 / 부분 통제 / 통제 불가 |
| 발생 시점 | D+n 또는 구간 |
| 징후(트리거) | 관측 가능한 사건·수치 |
| 영향 | 어느 산출물·목표가 어떻게 되는가 |
| 예방책 | 번호 조치 |
| 발생 시 대응 | 번호 조치 + 결정 주체 |

- 행 예시 1 : `R-03 | 중앙회 비용배분 합의 결렬·지연 | 고 | 통제 불가 | D+38~D+55 | 시산 회람 후 10영업일 무회신 / 배분 전제 자체 부정 | DL4-1 미서명 → 부속협약 체결 불가(GM-07 미달성) | 협의체 D+7 구성 / 대안 3안+시산 동시 제시 / 쟁점 3분해 | ①단계적 합의 전환(범위·주기 선확정, 배분비율은 잠정+사후정산) ②잠정비율=6개월 균등 후 실사용량 소급 ③D+50 미성립 시 발주처 에스컬레이션 + 미합의 사유·대안 문서 제출`
- 행 예시 2 : `R-07 | 현행 플랫폼 정보·데이터 접근 지연 | 중 | 부분 통제 | D+3~D+30 | 자료요청 후 10영업일 내 회신율 50% 미만 / D+20까지 계정 미발급 | 진단 착수 지연 → DL3-1·계측 요건 확정 지연 | 자료요청 목록 표로 제출(항목·기한·담당부서) / 권한 신청 D+1 개시 / 미제출 주간 노출 | ①인터뷰+화면확인으로 근거 대체하고 대체 사실 명시 ②접근 불가 영역은 진단 범위 제외 및 영향 기재(추정 금지)`

**차트1. 위험 지표 추이** (주간 보고용 · 별지)
- 차트 종류 : 다중 꺾은선 + 임계선
- 축 : 가로 = 주차(1~21주), 세로 = 정규화 지표값
- 계열 5개 : 주간 보고 5개 지표
- 임계선 : 각 계열의 경고 임계값을 수평 파선으로 표시, 교차 시점에 마커

## 5. 인접 절과의 경계 / 인용 근거

### 경계 자기점검

- **Ⅲ.3.4(유사 프로젝트 기반 해결방안)와의 경계** : 본 절은 **이 사업 고유의 위험 레지스터**다. Ⅲ.3.4는 **과거 프로젝트에서 실제 겪은 문제와 그때 적용한 해법의 카탈로그**이며 위험 항목을 다시 나열하지 않는다. 두 절은 "무엇이 위험한가"(본 절)와 "그 문제를 전에 어떻게 풀었는가"(Ⅲ.3.4)로 분담한다.
- **Ⅲ.2.2로 넘긴 것** : 버퍼의 배치 설계, 외부 일정 변경 시 재조정 규칙, 조기 인수 방식. 본 절은 버퍼를 **위험 지표(잔여 일수)** 로만 참조했다.
- **Ⅲ.2.3으로 넘긴 것** : 이견 조정 4단계 규칙의 상세. 본 절은 R-08의 예방책으로 **참조**만 했다.
- **Ⅲ.2.4로 넘긴 것** : 규제 추적 절차와 영향도 판정 기준. 본 절은 R-05의 트리거로 **A등급 누적 건수**만 사용했다.
- **Ⅳ.2(관리방안)로 넘긴 것** : 프로젝트 관리 체계·보고 체계·변경 관리 절차 일반, 공정계획 미준수 시의 일반적 위험관리 방법·절차(PD-IV-2c). 본 절은 **본 사업 고유 위험 10건**에 한정했다.
- **Ⅳ.1로 넘긴 것** : 투입인력 구성과 교체 절차의 상세. 본 절은 R-10의 대응으로만 언급했다.

- **[가정]** 위험 등급(고/중/저) 판정은 제안사가 발생 가능성과 영향도를 종합하여 부여한 값이다. 착수 후 첫 위험 레지스터 갱신 시 발주처와 재조정한다.
- **[가정]** R-02의 대체 경로인 「Phase1 종료 조건 재정의(의결 → 상정 완료)」와 「잠정 책임 배분」은 제안사의 제안이며, 발주처 준법감시부의 수용 여부에 따라 실행된다. 수용되지 않을 경우 이사회 의결 완료를 Phase1 종료 조건으로 유지하고 다른 산출물의 확정 순서를 재배치한다.
- **[가정]** R-03의 잠정 비율안(최초 6개월 균등분담 후 실사용량 기준 소급 정산)은 제안사 기본안이다. 실제 적용 여부와 소급 기준일은 양 기관 합의로 정한다.
- **[가정]** 실질 상충 비율의 설계 전제(10% 내외)와 경고 임계값(20%)은 제안사의 유사 사업 경험에 근거한 값이다. 첫 산출물 검수 결과로 재산정한다.
- **[가정]** 주간 보고 5개 지표의 경고 임계값(버퍼 10일 / A등급 3건 / 미제출 0 / 보류 0 / 상충 20%)은 제안사 설정치이며, 착수 시 발주처와 확정한다.
