# 작업지시서 — Ⅲ.2.3 전략2) 은행·상호금융 이원 산출물 전략

## 1. 이 문서가 답해야 할 질문

> **같은 산출물을 두 주체가 각각 갖되 일관성을 잃지 않으려면 어떻게 만들고 어떻게 검수받는가?**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. **공통 골격 + 기관별 델타** 방식의 정의: 어느 부분이 공통이고 어느 부분이 갈라지는지를 산출물 유형별로 판정 (예: AI윤리원칙은 공통, 책무구조도는 완전 분리, 위험평가 기준은 공통·등급 임계값은 개별)
2. **은행과 상호금융의 차이 요인을 구체적으로 짚을 것** — 업무특성(대고객 채널 구조), 규모(조합 단위 분산), 규제 적용 범위(상호금융의 적용 법령 차이). RFP GM-09가 이 3가지를 명시함
3. **검수 병렬화 방안**: 두 주체 검수를 순차로 돌리면 Phase1이 무너진다. 동시 검토 → 합동 조정회의 → 각각 승인 구조를 제안하고 소요일 가정 제시
4. 두 기관 의견이 충돌할 때의 **이견 조정 절차와 결정 주체**
5. 산출물 19종 중 이원화 대상 / 단일 작성 대상 구분표

## 3. 담당 요구사항 (전수)

아래 요구사항은 **이 문서가 책임진다.** 다른 절에서 다뤄지지 않는다.
각 요구를 '어떻게 충족시킬 것인가'로 답할 것. 요구사항 문장을 옮겨 적는 것은 답이 아니다.

| ID | 요구사항 | 유형 | Phase |
|---|---|---|---|
| `GM-09` | 은행과 상호금융의 업무특성·규모·규제 적용 범위 차이를 반영한 맞춤형 거버넌스 체계를 설계할 것 | 필수 | 전기간 |
| `GM-15` | 산출물을 은행 및 중앙회(상호금융) 각각에 대해 작성하고 각각 검수받을 것 | 필수 | 전기간 |
