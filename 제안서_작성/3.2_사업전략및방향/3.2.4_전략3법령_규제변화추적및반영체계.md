# Ⅲ.2.4 전략3) 법령 · 규제 변화 추적 및 반영 체계

> **메타** | 요구사항: `GM-10, GM-12, GM-17` | Phase: 전기간 | 예상 분량: 2장

---

## 1. 거버닝 메시지

> **AI 규범은 사업 5개월 동안 고정되어 있지 않으므로, 추적 대상 규범을 목록으로 고정하고 모니터링 주기를 배정한 뒤, 개정 인지에서 산출물 재검수까지를 「인지 1일 → 판정 2일 → 보고 즉시 → 합의 3일 → 반영 5~15일」의 시한이 붙은 절차로 운영한다.**

- **서브메시지 1** — 추적 대상은 **10개 규범 + 3개 감독 채널**이며, 각각에 모니터링 소스(관보·당국 보도자료·협회 공지)와 주기(주 1회 / 월 1회)를 배정한다. "동향을 살핀다"는 서술은 추적 체계가 아니다.
- **서브메시지 2** — 개정이 발생했다고 모두 반영하지 않는다. **즉시 반영 / 차기 개정 반영 / 모니터링만** 3단계로 판정하되, GM-12가 "즉시 보고"를 명시했으므로 **판정 결과와 무관하게 인지 즉시 보고를 먼저 수행**한다.
- **서브메시지 3** — 이미 검수·확정된 산출물이 규제 변경으로 다시 열릴 때를 위해 **버전 규칙과 부분 재검수 규칙**을 미리 정한다. 전체 재검수를 반복하면 사업이 끝나지 않는다.

### 2.2 영향도 판정 기준 3단계

| 판정 | 요건 (하나라도 해당하면 그 등급) | 처리 |
|---|---|---|
| **A. 즉시 반영** | ① 시행일이 사업기간 내 또는 사업 종료 후 6개월 내인 **법률·시행령 개정** ② 10월 개시 대상 3개 과제의 **적법성·보안성 판단을 바꾸는** 개정 ③ 이미 확정한 산출물의 **조문 내용과 충돌**하는 개정 ④ 감독기관이 특정 조치를 **기한을 정해 요구** | 해당 산출물 즉시 재개정 착수, 재검수 |
| **B. 차기 개정 반영** | ① 시행일이 사업 종료 후 6개월 이후인 개정 ② 산출물의 **부속 자료·예시·참고 조항**에만 영향 ③ 가이드라인 중 **권고 수준**의 변경 | 「차기 개정 반영 목록」에 등재하고 Phase 종료 시 일괄 반영, 사업 종료 시 미반영분은 발주처에 이관 |
| **C. 모니터링만** | ① 입법예고·의견수렴 단계로 **확정되지 않은** 개정안 ② 타 업권 전용 규범 ③ 수협의 AI 활용 범위 밖의 영역(예: 의료기기·교통) | 등록부에 기록만 하고 상태 변화 시 재판정 |

**판정 주체와 시한** — 제안사 PM과 규제 담당 컨설턴트가 **인지 후 2영업일 내** 1차 판정하고, A등급 판정 건은 발주처 준법감시 부서 확인을 거쳐 확정한다. 판정이 갈리면 **보수적으로 상위 등급(A 방향)을 채택**한다.

### 2.3 즉시 보고 및 반영 절차 — 단계별 시한 (GM-12)

GM-12는 *"즉시 발주처에 보고하고 산출물에 반영하는 방안"* 을 요구한다. 다음 6단계로 운영하며, **보고는 판정보다 앞선다.**

| 단계 | 내용 | 수행 주체 | 시한 |
|---|---|---|---|
| **1. 인지** | 모니터링 주기에 따른 정기 확인 또는 감독 채널을 통한 수시 인지. 등록부에 인지일·소스·원문 링크를 기록 | 제안사 규제 담당 | 발생일 기준 **주기 내(주 1회 대상은 7일 내)** |
| **2. 즉시 보고** | **판정을 기다리지 않고** 발주처 사업담당자에게 1차 통지. 통지 내용 = 개정 사실 / 시행일 / 영향 가능 산출물 목록(추정) | 제안사 PM | 인지 후 **1영업일 내** |
| **3. 영향도 판정** | 3단계 판정 및 영향 산출물·조문 특정. 판정 근거를 등록부에 기록 | 제안사 + 발주처 준법 | 인지 후 **2영업일 내** |
| **4. 반영 범위 합의** | A등급 건에 대해 **①반영 조문 ②재검수 범위 ③일정 영향 ④추가 공수 여부**를 발주처와 합의. 합의 결과를 「규제 변경 반영 합의서」로 남김 | 제안사 + 발주처 | 판정 후 **3영업일 내** |
| **5. 산출물 재개정** | 합의된 범위로 조문 개정, 델타 블록 및 「기관별 상이 항목 일람표」 동시 갱신 | 제안사 | 합의 후 **5~15영업일**(범위에 따름) |
| **6. 재검수** | 부분 재검수 규칙(2.4)에 따라 변경 조문 중심으로 검수 | 발주처·중앙회 | 재개정 후 **5영업일** |

**총 소요** — 인지에서 재검수 완료까지 **최장 26영업일**. Phase1 구간에서 A등급 변경이 발생하면 이 26영업일이 버퍼를 잠식하므로, Ⅲ.2.2의 잔여 버퍼 추이 관리와 연동하여 주간 보고한다.

### 2.4 확정 산출물의 재개정 — 버전관리와 부분 재검수 규칙

#### 버전 규칙

| 버전 형식 | 부여 조건 | 예 |
|---|---|---|
| `v0.x` | 초안 단계(초안 인수 대상 포함) | v0.1, v0.2 |
| `v1.0` | 확정본 인수 완료 | v1.0 |
| `v1.x` | **규제 변경 외의 사유**(오탈자, 참조 수정, 서식 보완)로 인한 개정 | v1.1 |
| `v2.0` | **규제 변경(A등급)에 따른 조문 개정** | v2.0 |

- 모든 개정본에는 **개정 이력표**(개정 버전 / 개정일 / 개정 사유 / 근거 규범 조항 / 변경 조문 번호 / 승인자)를 문서 앞부분에 부속한다.
- 규제 변경에 따른 개정은 **근거 규범의 조항 번호를 반드시 기재**한다. 감독기관 검사 시 개정 사유의 소명 자료가 된다.

#### 부분 재검수 규칙

전체 재검수를 반복하면 Phase1 일정이 유지되지 않는다. 변경 범위에 비례한 재검수를 적용한다.

| 변경 범위 | 재검수 범위 | 소요 | 승인 |
|---|---|---|---|
| 단일 조문의 문언 수정(의미 불변) | **변경 조문만** | 2영업일 | 부서 전결 |
| 단일 조문의 의무 내용 변경 | 변경 조문 + **참조 관계에 있는 조문** | 5영업일 | 원 승인권자 |
| 다수 조문 또는 체계 변경 | **문서 전체** | 15영업일 | 원 승인권자 |
| 위험평가 항목·배점·임계값 변경 | 문서 전체 + **기(旣)수행 평가 결과 재산정** | 15영업일 + 재평가 | AI윤리위원회 |

**참조 관계 추적** — 조문 간 참조 관계는 산출물 작성 시 **「조문 참조 관계도」** 로 함께 작성하여, 재개정 시 영향 조문을 빠짐없이 식별한다. 이 관계도는 Ⅲ.4.6의 산출물 구성 항목에 포함한다.

### 2.5 능동 확대 트리거 (GM-17)

RFP Ⅱ-3은 *"명시된 과제 및 산출물은 예시적 범위"* 이며 추가 요구가 확인되면 **제안사가 능동적으로 파악하여 필요한 과제 및 산출물을 추가 제시**하도록 요구한다. 추적 과정에서 다음 조건에 해당하는 항목을 발견하면 추가 제안 절차를 발동한다.

#### 트리거 조건 4개

| # | 조건 | 예 |
|---|---|---|
| T1 | 법령·시행령이 **의무**로 규정한 사항 중 RFP 산출물 19종에 **대응물이 없는** 것 | AI기본법 시행령 제27조제1항의 **홈페이지 게시 의무**(위험관리방안 주요 내용·설명 방안·이용자 보호 방안·관리감독자 성명·연락처) |
| T2 | 가이드라인 점검항목 99개 중 **어느 산출물도 충족을 증명하지 못하는** 항목 | 보안성 원칙 ㉗(외부 AI서비스의 모델 개선 목적 데이터 재사용 금지 계약 명시) |
| T3 | 감독기관이 검토 과정에서 **문서로 요구**했으나 RFP에 없는 항목 | 금융보안원 실사 과정의 추가 자료 요구 |
| T4 | 사업 중 신설·개정된 규범이 **새로운 문서의 작성을 요구**하는 경우 | 고영향 AI 영향평가서 |

#### 추가 제안 절차

`발견 → 근거 조항 특정 → 미대응 시 리스크 서술 → 제안 산출물 정의 → 공수 판정(기본 범위 흡수 / 별도 공수) → 발주처 제시`

**공수 판정 기준** — 기존 산출물의 장(章) 추가 또는 부속 서식 추가로 해결되면 **기본 범위 내 흡수**한다. 독립 문서 작성이 필요하고 예상 공수가 **5인일(人日)을 초과**하면 별도 공수로 구분하여 제시한다. 이 판정 결과는 발주처의 비용 협상 판단 자료가 된다.

**제안 시점에 이미 발견한 항목** — 본 제안 작성 과정에서 위 트리거로 발견한 추가 과제·산출물은 **Ⅲ.4.7에 목록과 근거를 제시**했다. 사업 착수 전에 이미 능동 확대를 수행했다는 것이 GM-17에 대한 실질 응답이다.

## 3. 제안서용 요약 · 논리 구조

**논리 골격 : [전제 부정] → [대상 고정] → [판정] → [시한 절차] → [재개정 규율] → [능동 확대]**

- **[전제 부정]** *"5개월 동안 규범이 고정되어 있다"* 는 전제 폐기 → 검수 마친 산출물이 납품 시점에 낡을 위험
- **[대상 고정]** 추적 대상 **16개** = 법률·시행령 8 + 행정규칙·가이드라인 5 + 감독 채널 3
  - 주 1회 추적 : AI기본법·시행령 / 금융혁신법(Phase1) / 가이드라인 / AI RMF / 보안 안내서
  - 산출 : **규범 대조 매트릭스**(규범→조항→의무→내규 조문→충족/부분충족/공백), 공백 = 즉시 개선과제
- **[판정]** 3단계 — **A 즉시 반영 / B 차기 개정 반영 / C 모니터링만**
  - 판정 갈리면 **보수적으로 상위 등급 채택**
- **[시한 절차]** 6단계, **보고가 판정보다 앞선다**(GM-12 "즉시 보고")
  - `인지(주기 내) → 즉시 보고(1영업일) → 판정(2영업일) → 반영 범위 합의(3영업일) → 재개정(5~15영업일) → 재검수(5영업일)`
  - **총 최장 26영업일** → Phase1 잔여 버퍼와 연동 주간 보고
- **[재개정 규율]** 버전 `v0.x 초안 / v1.0 확정 / v1.x 비규제 개정 / v2.0 규제 개정` + 개정 이력표에 **근거 조항 필수 기재**
  - 부분 재검수 4단계 : 문언수정 2일 / 의무변경 5일 / 체계변경 15일 / **평가 배점 변경 15일 + 기수행 평가 재산정**
  - 「조문 참조 관계도」로 영향 조문 누락 차단
- **[능동 확대]** 트리거 T1~T4 → 근거 조항 → 리스크 → 제안 산출물 → **공수 판정(5인일 초과 시 별도 공수)**
  - **제안 시점에 이미 발견한 항목은 Ⅲ.4.7에 제시** ← GM-17에 대한 실질 응답

## 4. 시각적 표현 방안

### (a) 슬라이드 분할 구조 — 2장

- **1장 : `중앙 다이어그램 + 주변 설명`** — 중앙에 추적 대상 규범 지도(3계층), 주변에 모니터링 주기·영향 경로·대조 매트릭스 구조 예시
- **2장 : `4분할 세로 흐름`** — 인지 → 판정 → 보고·합의 → 반영·재검수 4단계 카드를 좌→우 배치, 각 단계에 소요일 배지. 하단에 능동 확대 트리거 띠

### (b) 도해 지시

**1장 중앙 — 추적 대상 규범 지도**
- 슬라이드 중앙을 규범 지도가 차지하고, 좌·우·하단 여백에 주변 설명을 배치한다
- 지도는 3계층 수평 띠로 구성. 위에서 아래로 **① 법률·시행령(8) ② 행정규칙·가이드라인(5) ③ 감독 채널(3)**
- 계층별로 색상과 테두리를 다르게 처리 : ①은 실선 굵은 테두리(**위반 시 제재**), ②는 실선 가는 테두리(**감독 판단 기준**), ③은 점선 테두리(**문서화되지 않은 요구**). 테두리 굵기가 곧 구속력의 시각화
- 각 규범 블록 우측 상단에 **주기 배지** : `주1` (강조색) / `월1` (회색) / `상시`
- 주 1회 대상 6개는 배경을 진하게 처리하여 **추적 부하가 어디에 몰리는지** 드러낸다
- 우측에 세로 패널 : 각 규범에서 본 사업 산출물로 향하는 화살표를 묶어 **「규범 → 산출물 영향 경로」** 로 표시. 화살표가 가장 많이 모이는 산출물(DL1-1 AI 업무규정)을 굵게 강조

**1장 주변 — 규범 대조 매트릭스 구조**
- 지도 하단 여백에 5열 구조를 실제 표 형태로 2~3행 예시와 함께 제시(아래 표1)
- 「대응 상태」 열의 셀 색상 3종(충족 = 연녹 / 부분충족 = 연황 / 공백 = 연적)을 범례와 함께 표시
- 공백 셀에서 오른쪽으로 뻗는 화살표 → **「개선과제」 아이콘** → **「Ⅲ.4.7 추가 제안」** 으로 연결

**2장 상단 — 반영 절차 4분할 세로 흐름**
- 카드 4장을 좌→우 배치 : `① 인지` / `② 판정` / `③ 보고·합의` / `④ 반영·재검수`
- **카드 ①과 ③ 사이에 위쪽으로 우회하는 별도 화살표**를 그려 *"즉시 보고는 판정을 기다리지 않는다"* 를 표현한다. 이 우회 화살표가 이 도해의 핵심 — 순차 흐름의 예외임을 시각적으로 보이는 장치
- 각 카드 하단에 소요일 배지 : `주기 내` / `2영업일` / `1+3영업일` / `5~15+5영업일`
- 카드 ② 안에 3단계 판정 분기(A/B/C)를 소형 분기도로 삽입하고, A만 카드 ④로 연결, B는 「차기 개정 목록」 아이콘으로, C는 「등록부 기록」 아이콘으로 빠지게 그린다
- 최우측에 **총 26영업일** 누적 배지

**2장 하단 — 능동 확대 트리거 띠**
- 가로 4분할 : T1(법령 의무 미대응) / T2(점검항목 미충족) / T3(감독기관 요구) / T4(신설 규범)
- 각 칸에 대표 예시 1개를 짧게 표기
- 띠 우측 끝에 화살표로 **`Ⅲ.4.7`** 라벨 연결
- 띠 아래에 공수 판정 기준 한 줄 : *"장(章)·서식 추가로 해결 → 기본 범위 흡수 / 독립 문서 + 5인일 초과 → 별도 공수"*

## 5. 인접 절과의 경계 / 인용 근거

### 경계 자기점검

- **Ⅲ.4.7로 넘긴 것** : 능동 확대 트리거로 **실제 발견한 추가 과제·산출물의 내용, 근거 조항, 리스크, 공수 판정 결과**. 본 절은 **트리거 조건과 제안 절차라는 메커니즘**만 기술했고, T1·T2의 예시 2건은 메커니즘 설명을 위한 인용에 그쳤다.
- **Ⅲ.2.1과의 경계** : 규제추적 원칙의 선언과 장치 3개 요약은 Ⅲ.2.1이 했다. 본 절은 그 장치의 **실행 규약**을 담당했다.
- **Ⅲ.2.2로 넘긴 것** : 잔여 버퍼 관리와 외부 일정 변경 시 재조정 규칙. 본 절은 **규제 변경이 버퍼를 잠식한다는 연동 관계**만 명시했다.
- **Ⅲ.2.5로 넘긴 것** : 「사업 중 법령 개정」 위험의 등급 판정과 발생 시 대응 시나리오. 본 절은 **상시 운영 절차**를 다뤘고 위험 레지스터를 다시 쓰지 않았다.
- **Ⅲ.4.2로 넘긴 것** : AI기본법 조항별 대응 설계(고영향 분류체계, 위험평가체계, 문서화 규칙)의 내용. 본 절은 **추적 대상으로서의 조항 목록**만 제시했다.
- **Ⅳ.3(품질보증)으로 넘긴 것** : 산출물 형상관리 도구와 검수 조직. 본 절은 **버전 규칙과 부분 재검수 범위**만 정의했다.

### [가정] 목록

- **[가정]** 추적 대상 16개 목록은 제안사가 제안 시점에 식별한 초안이다. 착수 후 2주 내 발주처 준법감시·정보보호 부서와 확정하며, 수협 고유의 내부 준칙(보안업무 취급준칙, 전산보안 업무방법서 등)을 추가 대상으로 편입한다.
- **[가정]** 모니터링 주기(주 1회 / 월 1회)는 제안사 설정치다. Phase1 구간에는 AI기본법·시행령, 금융혁신법, 가이드라인 3종을 주 1회로 상향 운영하며, Phase2 진입 시 발주처와 주기를 재조정한다.
- **[가정]** 반영 절차의 각 단계 시한(1·2·3·5~15·5영업일)은 제안사 자체 기준이다. 감독기관이 별도 기한을 지정한 요구사항은 그 기한이 우선한다.
- **[가정]** 별도 공수 판정 기준을 「독립 문서 + 5인일 초과」로 설정한 것은 제안사 기준이며, 계약 협상 시 발주처와 조정한다.
- **[가정]** 「기관별 상이 항목 일람표」와 「조문 참조 관계도」는 RFP 산출물 목록에 없는 부속 자료다. 각 산출물의 구성 항목으로 무상 포함하며 별도 공수를 요청하지 않는다.
