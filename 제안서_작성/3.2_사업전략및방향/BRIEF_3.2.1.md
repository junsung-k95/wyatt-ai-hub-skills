# 작업지시서 — Ⅲ.2.1 3대 추진원칙 : 즉시적용성·이원산출·규제추적

- **저장 경로**: `제안서_작성/3.2_사업전략및방향/3.2.1_3대추진원칙.md`

- **Phase 성격**: 전기간

## 1. 이 문서가 답해야 할 질문

> **이 사업을 관통하는 원칙 3개는 무엇이며, 각 원칙이 실제 어떤 산출물과 절차로 구현되는가?**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. 원칙1 **즉시적용성** — RFP GM-16 '바로 업무에 적용할 수 있어야 함' / GM-18 '단순 요건 충족을 넘어'. 이를 구현하는 장치를 구체적으로: 규정 초안이 아니라 개정안 조문 형태로 산출, 매뉴얼에 실제 서식·화면·담당자 지정, 시뮬레이션으로 실효성 사전 검증
2. 원칙2 **이원산출** — 은행/중앙회 각각 작성·검수(GM-09, GM-15). 공통 골격 + 기관별 델타 방식
3. 원칙3 **규제추적** — 법령 개정 시 즉시 보고·반영(GM-12), 예시적 범위의 능동 확대(GM-17)
4. 각 원칙마다 '이 원칙이 없으면 무엇이 실패하는가'를 1줄로 — 원칙을 구호가 아니라 위험 대응으로 제시할 것

## 3. 담당 요구사항 (전수)

아래 요구사항은 **이 문서가 책임진다.** 다른 절에서 다뤄지지 않는다.
각 요구를 '어떻게 충족시킬 것인가'로 답할 것. 요구사항 문장을 옮겨 적는 것은 답이 아니다.

| ID | 요구사항 | 유형 | Phase |
|---|---|---|---|
| `PD-III-2a` | 사업목표 달성을 위한 구체적인 사업전략 및 방향을 위험요소를 고려하여 창의적이고 타당한 대안과 함께 제시할 것 | 필수 | - |
| `GM-18` | 단순 요건 충족 수준을 넘어 실제 운영환경에서 즉시 적용 가능한 실행력 있는 거버넌스 체계를 제시하고, 이를 위한 구체적 방법론과 근거를 제안서에 포함할 것 | 필수 | 전기간 |
| `GM-16` | 산출물의 수준은 바로 업무에 적용할 수 있는 수준일 것 | 필수 | 전기간 |
