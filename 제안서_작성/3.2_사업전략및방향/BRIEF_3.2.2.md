## 1. 이 문서가 답해야 할 질문

> **10월 서비스 개시에서 거꾸로 세었을 때, 각 산출물은 언제까지 무엇이 끝나 있어야 하는가?**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. **역산 기준점을 명시**: 10월 혁신금융서비스 개시일 → 금융보안원 보안성 검토 완료 필요일 → 실사자료 제출일 → 현장점검 대응 준비 완료일 → 보안대책서 확정일 → 착수일
2. 계약체결일이 미정이므로 **모든 일정을 D+n(착수일 기준 상대일)으로 표기**할 것. 절대 날짜 단정 금지
3. **발주처 내부 승인 소요기간을 별도 항목으로 가정하고 명시**할 것 (예: 위원회 상정 주기 월 1회 가정 시 D+35 이전 안건 제출 필요). 가정은 가정이라고 밝히고 착수 시 확정한다고 쓸 것
4. **조기 인수(GM-05) 대상 산출물을 지정**하고, 부분 인수 방식(초안 인수 → 확정본 인수 2단계)을 제안할 것
5. 버퍼 설계: 어느 구간에 며칠의 여유를 두었고 왜 거기인지
6. 금보원 점검·금감원 보고 일정이 변경될 경우의 재조정 규칙(GM-04)
