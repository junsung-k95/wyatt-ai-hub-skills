## 1. 거버닝 메시지

> **본 사업의 목표는 「AI 거버넌스 문서를 만드는 것」이 아니라 「10월 혁신금융서비스가 규제 지적 없이 개시되고, 그 다음 날부터 은행과 상호금융이 같은 규칙·같은 정산기준으로 AI를 운영하는 상태」를 만드는 것이므로, 모든 목표는 외부 데드라인 종속 구조 위에 세우고 계량 판정기준을 붙여 제시한다.**

- **서브메시지 1** — 최상위 목표는 하나다. *"10월 개시 시점에 AI 거버넌스가 실제로 작동하고 있을 것."* 나머지 4개 하위목표는 이 목표를 떠받치는 구조물이지 병렬 항목이 아니다.
- **서브메시지 2** — 각 하위목표에 「무엇이 몇 건, 언제까지, 어떤 상태로」를 판정하는 계량 기준을 부여하여, 사업 종료 시 달성 여부를 발주처가 다툼 없이 판정하도록 한다(RFP FM-05 계량화 요구 대응).
- **서브메시지 3** — 은행과 중앙회(상호금융)는 도달점이 다르다. 은행은 *"자기 이름으로 규제기관에 설명하고 증적을 제시하는 상태"*, 상호금융은 *"위탁받은 서비스를 자기 내규로 통제하고 비용을 자기 근거로 지급하는 상태"* 를 목표로 분리 설정한다.

## 2. 본문

### 2.1 목표 체계를 세우는 방식 — 왜 2단인가

RFP Ⅰ-3 사업목적은 7개 항목을 병렬로 나열하지만, 그중 2개에만 **"(우선과제)"** 표기가 붙어 있다. 이 표기는 단순 강조가 아니라 **일정 종속 구조의 선언**이다. 우선과제 2개(10월 개시 대비 거버넌스 + 과금체계 / 보안대책 + 금융보안원 보안성 심사)는 수협이 통제하지 못하는 외부 일정에 걸려 있고, 나머지 5개는 사업기간 내에서 순서를 조정한다. 따라서 7개를 평면 나열하면 임계경로가 사라진다.

본 제안은 7개 사업목적을 **최상위 목표 1개 + 하위 목표 4개**의 2단 체계로 재구성한다. 재구성 규칙은 세 가지다.

1. **외부 데드라인에 걸린 것을 최상위로 올린다.** OBJ-01·03·04는 10월이라는 고정 시점에 종속되므로 최상위 목표의 구성요소로 흡수한다.
2. **"상대방의 서명이 필요한 것"을 별도 목표로 분리한다.** OBJ-02(과금체계)는 문서 작성 난이도가 아니라 **중앙회 합의 난이도**가 본질이므로 독립 목표로 세운다.
3. **Phase2 항목은 "무엇을 갖추는가"가 아니라 "무엇을 운영하게 되는가"로 다시 쓴다.** OBJ-06~OBJ-10을 산출물 나열이 아니라 운영 상태로 정의한다.

### 2.2 최상위 목표

> **[최상위 목표] 2026년 10월 혁신금융서비스 3개 과제가 「거버넌스 승인을 받은 상태」로 개시되고, 금융보안원 보안성 검토를 지적사항 없이 통과한다.**

다음 세 가지가 동시에 성립할 때만 달성으로 판정한다.

| 판정 요소 | 계량 판정기준 | 근거 요구사항 |
|---|---|---|
| 거버넌스 승인 | 10월 출시 대상 3개 과제 전건에 대해 **「AI서비스 출시 전 거버넌스 승인서」 3건 발급 완료**(개시일 D-14 이전) | OBJ-01, DL1-5 |
| 위험평가 완료 | 3개 과제 전건 **위험평가서 3건 + 통제·관리 계획서 3건 확정**, 잔여위험 점수·등급 확정, 고위험 판정 건은 AI윤리위원회 사전승인 의결서 첨부 | OBJ-01, DL1-3 |
| 보안성 검토 통과 | **금융보안원 보안성 검토 지적사항 0건**(보완요구 발생 시 **회신 5영업일 이내** 종결), 보안대책서 1식·실사자료 1식 사전 제출 완료 | OBJ-03, OBJ-04, DL2-1, DL2-2 |

**이 목표가 실패하면 나머지 목표의 달성 여부는 의미를 잃는다.** 서비스가 열리지 못하면 거버넌스 고도화도 플랫폼 로드맵도 사업 성과로 인정받지 못한다. 본 제안이 Phase1 역산 일정(Ⅲ.2.2)과 위험 대응(Ⅲ.2.5)에 지면을 집중 배분하는 이유가 여기에 있다.

### 2.3 하위 목표 4개와 달성 판정기준

#### 목표 1. 규제 공백 없는 AI 거버넌스 규범체계 확보 (OBJ-06, OBJ-07)

*"AI기본법·금융분야 인공지능 가이드라인·금감원 AI RMF가 요구하는 사항 중, 수협의 내규·조직·절차로 대응되지 않는 항목을 0으로 만든다."*

| 판정기준 | 값 |
|---|---|
| 규범 대조 커버리지 | 「금융분야 인공지능 가이드라인」 7대 원칙 **점검항목 99개**(거버넌스 8·합법성 11·보조수단성 12·신뢰성 15·금융안정성 9·신의성실 6·보안성 38) 전항목에 대응 내규 조문 또는 절차를 매핑, **미대응 0건** |
| 법령 준수 판정 | AI기본법 제31조(투명성)·제33조(고영향 확인)·제34조(사업자 책무)·제35조(영향평가) 및 시행령 제23조·제25조·제27조·제28조 각 항에 대한 **「AI기본법 위반 여부 점검 보고서」 1건**, 위반 항목 0건 확인 |
| 규범 문서 확정 | AI 업무규정 1건 + AI윤리위원회 운영준칙 1건 + 준칙 4종(위험관리 / 개발·이용·운영 / 보안 / 소비자보호) = **6건 제·개정안 확정 및 승인 상신 완료** |

*"양 기관이 이견 없이 서명하는 산식을 만들고, 그 산식이 실제 계측 데이터로 계산되는 것까지 검증한다."*

### 2.4 은행과 중앙회(상호금융)의 도달점 차이

두 기관은 같은 플랫폼을 쓰지만 **규제상 지위와 책임 구조가 다르므로 목표 도달점도 다르게 설정한다.** 은행은 혁신금융서비스의 지정 주체이자 금융보안원 보안성 검토의 대응 주체이므로, 도달점은 *"AI 의사결정 결과를 자기 이름으로 감독당국에 설명하고 그 근거 문서를 5년간 제시하는 상태"*(AI기본법 시행령 제27조제2항의 문서 보관 의무 수준)이다. 중앙회(상호금융)는 은행이 제공하는 AI서비스를 위탁 이용하는 구조이므로, 도달점은 *"위탁받은 AI서비스에 대해 자기 내규로 통제 근거를 갖추고, 조합 단위까지 내려가는 이용 실적에 근거해 비용을 지급하는 상태"*이다. 이 차이 때문에 AI윤리원칙과 위험평가 항목·배점은 공통으로 두되, 책무구조도·위험등급 임계값·소비자보호 채널은 기관별로 분리 설계한다(설계 방식은 Ⅲ.2.3).

## 3. 제안서용 요약 · 논리 구조

**논리 골격 : [문제 인식] → [목표 재정의] → [판정기준] → [기관별 분화] → [효과]**

- **[문제 인식]** RFP 사업목적 7개는 평면 나열 → 우선과제 2개만 외부 데드라인 종속 → **평면 나열을 그대로 목표로 삼으면 임계경로를 놓친다**
- **[목표 재정의]** 최상위 목표 1개로 수렴 → **"10월, 승인된 상태로 개시, 지적 0건"**
  - 하위목표 4개 = ① 규제 공백 0 ② 서명 가능한 비용 산식 ③ 담당자 교체 내성 운영표준 ④ 확장 수용 플랫폼 청사진
- **[판정기준]** 4개 목표 × 4개 지표 = **16개 판정기준을 전부 건수·시점·상태로 표기** → 종료 시 달성 여부 다툼 없음
  - 대표 지표 : 점검항목 **99개 미대응 0건** / 승인서 **3건** / 보안성 지적 **0건** / 협의서 **양측 서명 1건** / 시산 **1회 이상**
- **[기관별 분화]** 은행 = *설명책임 주체* → 5년 증적 제시 상태 / 상호금융 = *위탁 이용 주체* → 자기 내규 통제 + 조합단위 실비 지급 상태
- **[효과]** 종료 시점의 상태가 문서 목록이 아니라 **작동 여부**로 정의됨 → RFP GM-16(바로 업무 적용)·GM-18(단순 요건 충족을 넘어)의 직접 충족

## 4. 시각적 표현 방안

### (a) 슬라이드 분할 구조 — 2장

- **1장 : `중앙 다이어그램 + 주변 설명`** — 중앙에 목표 체계 피라미드, 주변 4개 코너에 하위목표 카드
- **2장 : `좌우 2분할 비교`** — 왼쪽 "현재(규제 공백 상태)" ↔ 오른쪽 "사업 종료 시 확보 상태", 하단 가로 띠로 기관별 도달점 2단 분리

### (b) 도해 지시

**1장 — 목표 체계 피라미드(3단)**
- 최상단 : 단일 블록, 폭 60%, 진한 배경. 문구 = *"10월 혁신금융서비스 3개 과제, 승인된 상태로 개시 · 보안성 지적 0건"*. 블록 우측 상단에 **적색 캘린더 배지 "外部 고정일"** 을 부착해 통제 불가 데드라인임을 표시
- 중단 : 4개 블록 가로 등분(목표 1~4). 블록 상단에 Phase 배지(목표1 = Phase1·2 걸침 / 목표2 = Phase1 / 목표3·4 = Phase2)
- 하단 : 16개 판정기준을 4열 × 4행 소형 칩(chip)으로 배치, 각 칩은 위 목표 블록과 **세로 점선**으로 연결
- 최상단 ↔ 중단 사이 화살표는 **아래에서 위(↑)** 방향으로 그린다. *"하위목표가 최상위 목표를 떠받친다"* 는 종속 구조가 이 슬라이드의 핵심 메시지다
- 강조 지점 : 목표2 블록 테두리를 **파선(破線)** 으로 처리하고 *"상대방 서명 필요"* 라벨 부착 — 제안사가 단독으로 완료하지 못하는 유일한 목표임을 명시

**2장 — As-Is / To-Be 좌우 대비**
- 좌측 패널(회색조) : 5개 행 = 규범 / 조직 / 위험평가 / 비용기준 / 플랫폼, 각 행에 **공백 아이콘(빈 사각형)**
- 우측 패널(강조색) : 동일 5개 행에 확보 상태 문구 + **충족 아이콘(체크)** 및 산출물 번호(DL1-1 등) 배지
- 중앙 세로축에 화살표 1개, 축 위에 *"5개월 / Phase1 2개월 + Phase2 3개월"* 라벨
- 하단 가로 띠 : 좌 = 은행 도달점, 우 = 중앙회(상호금융) 도달점, 두 칸 사이에 **공통 골격 세로 띠**를 얇게 삽입

## 5. 인접 절과의 경계 / 인용 근거

### 경계 자기점검

- **Ⅲ.1.2(업무범위·과제구조)로 넘긴 것** : 과제1~4의 범위 정의와 과제 간 의존관계, Scope In/Out. 본 절은 *"무엇을 이룰 것인가"* 만 기술하고 *"무엇을 수행하는가"* 는 기술하지 않았다.
- **Ⅲ.1.3(Phase·우선순위)으로 넘긴 것** : 우선순위 판단 기준과 Phase1 산출물 9건의 정렬. 본 절은 목표의 Phase 귀속만 표기했다.
- **Ⅲ.2(전략)로 넘긴 것** : 데드라인 역산 방법, 이원 산출물 제작·검수 방식, 규제 추적 절차. 본 절은 목표 도달점의 기관별 차이만 1개 문단으로 기술했다.
- **Ⅲ.4.2~4.5(과제별 수행방안)로 넘긴 것** : 판정기준에 등장한 산출물의 내부 설계(위험평가 항목·배점, 산식, 아키텍처 계층 구성). 본 절은 **결과 상태의 계량 기준**만 제시했다.
