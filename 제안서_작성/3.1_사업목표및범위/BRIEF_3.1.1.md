## 1. 이 문서가 답해야 할 질문

> **수협은행·중앙회는 이 5개월이 끝났을 때 무엇을 갖게 되는가? 를 측정 가능한 목표 체계로 답한다.**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. 최상위 목표 1개 + 하위 목표 4개 이내의 **2단 목표 체계**. 각 목표는 RFP 문장 복사가 아니라 제안사 언어로 재정의할 것
2. 각 하위 목표마다 **달성 판정 기준**을 계량 형태로 제시 (예: '10월 서비스 개시 전까지 거버넌스 승인서 3건 발급 완료', '금보원 보안성 검토 지적사항 0건'). RFP FM-05가 계량화를 요구함
3. 목표 체계 최상단에 **10월 혁신금융서비스 개시 종속 구조**를 명시 — 이 사업의 성패가 외부 데드라인에 걸려 있다는 인식을 앞세울 것
4. 은행 / 중앙회(상호금융) 각각에 대해 목표 도달점이 어떻게 다른지 1문단
