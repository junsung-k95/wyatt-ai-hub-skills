## 1. 이 문서가 답해야 할 질문

> **RFP가 요구한 모든 것을 빠짐없이 읽고 제안서 어디에 담았는지를 평가위원이 한 눈에 확인하게 한다.**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. 이미 작성된 요구사항 추적표(257건)를 **제안서 지면에 맞게 압축**할 것. 전수 나열 금지
2. 카테고리별 집계표: 접두어 / 카테고리 / 건수 / 대응 목차 범위 (13개 카테고리)
3. **과업 요구사항 196건 100% 매핑, 미매핑 0건**이라는 사실을 명시하고, 전수 대조표는 별첨1 참조로 넘길 것
4. 요구사항 ID 체계를 어떻게 운영할 것인지 1문단 — 착수 후에도 이 ID로 산출물 검수 기준을 삼는다는 연결(PD-IV-3c와 호응)

## 3. 담당 요구사항 (전수)

아래 요구사항은 **이 문서가 책임진다.** 다른 절에서 다뤄지지 않는다.
각 요구를 '어떻게 충족시킬 것인가'로 답할 것. 요구사항 문장을 옮겨 적는 것은 답이 아니다.

| ID | 요구사항 | 유형 | Phase |
|---|---|---|---|
| `FM-01` | 제안요청서에서 요구하는 모든 사항을 기술할 것(향상된 내용으로 제안하는 것은 허용됨) | 필수 | - |
| `GM-13` | 본 사업목적과 성격에 적합한 구체적인 산출물 목록을 제시할 것 | 필수 | 전기간 |
