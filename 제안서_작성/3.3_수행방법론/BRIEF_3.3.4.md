## 1. 이 문서가 답해야 할 질문

> **같은 문제를 이미 겪어봤다 — 그때 무엇으로 풀었고, 여기에 어떻게 옮겨오는가?**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. **유사 프로젝트에서 실제 발생한 문제 → 적용한 해법 → 본 사업 이식 방안** 형식의 카탈로그 5~7건
2. 다룰 문제 유형: 규정 개정안이 내부 승인에서 반려된 사례, 위험평가 등급 기준을 두고 현업과 이견이 난 사례, 당국 실사에서 증적 부족 지적을 받은 사례, 다기관 비용배분 합의가 지연된 사례, 매뉴얼이 담당자 교체 후 작동하지 않은 사례
3. 각 건마다 **'그래서 본 사업에서는 무엇을 미리 한다'**로 끝맺을 것 (사전 조치의 형태로 전환)
4. 실적 프로젝트명은 발주처 비공개 의무를 고려해 업종·규모 수준으로 표기 (예: '시중은행 A, 자산 300조 규모')
