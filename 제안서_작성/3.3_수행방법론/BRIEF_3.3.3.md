## 1. 이 문서가 답해야 할 질문

> **19종 산출물이 언제, 누구 손을 거쳐, 어떤 상태로 넘어오는가?**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. **RFP 산출물 19종 전수 표**: 번호 / 명칭 / 주요 목차(내역) / Phase / 제출시기(D+n) / 이원화 여부 / 검수 주체
2. 각 산출물의 **'내역'을 실제 목차 수준으로** 적을 것 — 예: 'AI 업무규정: 총칙·적용범위·거버넌스 기구·위험관리·개발이용·소비자보호·보칙' 수준. 명칭만 나열하면 이 절은 실패임
3. **추가 제안 산출물**을 별도 구분해 표시(GM-17 대응, 상세는 3.4.7)
4. 산출물 제출 → 검토 → 협의 → 보완 → 승인의 상태 전이와 각 상태 소요일(GM-14)
