## 1. 이 문서가 답해야 할 질문

> **각 단계에서 어떤 기법을 쓰며, 그 기법은 언제 유효하고 무엇이 약점인가?**

이 질문에 답하지 못하면 분량과 무관하게 실패한 문서다.

## 2. 반드시 본문에 들어가야 할 것

1. **기법을 선택지 메뉴로 깔고 비교**할 것. 최소 포함 기법: 규정 갭분석(Gap Analysis), 규제 매핑(Regulatory Mapping), 위험평가 워크숍, 시나리오 기반 시뮬레이션, 체크리스트 감사, 벤치마킹, 원가 기반 배분 모형(ABC 등)
2. 각 기법마다 **[적용 단계 / 언제 쓰는가 / 장점 / 단점 / 본 사업 적용 대상]** 5열 비교표. **RFP Ⅳ-1 작성순서 표가 '특징 및 장단점'을 명시적으로 요구함(PD-III-3d) — 장단점 칸을 비우지 말 것**
3. 분석도구: 요구사항 추적표, 규정 대조 매트릭스, 위험 등급 산정 시트, 사용량 계측 모델 등 실제 산출물 형태로 제시
4. 기법 선택의 근거 — 왜 이 조합인가
