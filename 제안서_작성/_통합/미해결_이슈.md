# 미해결 이슈 — 발주처 확인 필요 목록

> 21개 소절의 `[가정]` 태그를 전수 수집했다. 제안서 작성 시점에 확정할 수 없어 가정으로 처리한 항목이며,

## 관리 방법

- 본 목록은 착수 시 **「미해결 이슈 등록부」로 전환**하여 주간 보고의 고정 항목으로 관리한다.
- 각 항목에 `확정 목표일 / 확인 주체 / 확정 결과 / 영향받은 산출물`을 부여하고, 확정되면 해당 산출물의 관련 기재를 갱신한다.
- 확정 결과가 가정과 다를 경우 **영향 범위를 산정해 발주처에 보고**한 뒤 산출물을 조정한다.
- 사업 중 새로 발생하는 가정은 동일 서식으로 등재하며, 규제 변경에서 비롯된 항목은 Ⅲ.2.4의 규제 추적 등록부와 상호 참조한다.
