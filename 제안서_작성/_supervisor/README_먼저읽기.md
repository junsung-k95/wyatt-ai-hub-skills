## v1.1에서 고친 것

v1.0의 파일명에 Windows 금지문자 `:` 가 들어 있어 탐색기 압축 해제가 실패했습니다.
파일명에서 `: ( ) [ ] · ,` 를 제거하고 UTF-8 파일명 플래그를 설정해 다시 압축했습니다.

압축 해제가 또 안 되면 **7-Zip 또는 반디집**으로 풀어 주세요. Windows 탐색기 기본 압축 해제는
한글 파일명 zip에서 실패하는 경우가 있습니다.
